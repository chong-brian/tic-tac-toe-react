# Tic-Tac-Toe

A tic-tac-toe game built with React, built with [Vite](https://vite.dev/).

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode with hot module reloading.<br />
Open the URL printed in the terminal (defaults to [http://localhost:5173](http://localhost:5173)) to view it in the browser.

### `npm run build`

Builds the app for production to the `dist` folder, minified and ready to deploy.

### `npm run preview`

Serves the production build from `dist` locally, for a final check before deploying.

### `npm run lint`

Runs ESLint over the project.
